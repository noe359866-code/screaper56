🎬 Peerflix Ingest

Busca tus películas y series en 5 addons Stremio (Peerflix, TorrentsDB, Torrentio, ThePirateBay+ y Ytztvio), fusiona por info_hash y se queda con solo 2 torrents por título: 🇪🇸 el mejor en español (castellano o latino) y 🇬🇧 el mejor en inglés, cada uno con los mejores trackers. Funciona sin token: procesa la lista en tu navegador o pide la ingesta con un Issue de GitHub.

Ajustes

Nada de esto es obligatorio. Sin token ni claves puedes procesar listas en el navegador, ver lo publicado y pedir ingestas por Issue. Todo se guarda solo en el localStorage de este navegador.

Repositorio de GitHub

Con token (fine-grained, solo este repo, permisos Contents y Actions en lectura/escritura), ☁️ Guardar en el repo actualiza watchlist.txt y lanza la Action directamente. Sin token, abre un Issue ya relleno. Lo envías tú con tu sesión de GitHub y la Action hace el resto.

Supabase opcional

Solo lectura: estos ajustes sirven para ver la tabla torrents en el Dashboard, no para guardar. Para escribir, configura SUPABASE_URL y SUPABASE_SERVICE_ROLE_KEY en Settings → Secrets and variables → Actions del repositorio y usa “☁️ Guardar en el repo / BD” sin Dry-run. Nunca pongas la service-role key en esta web.

Sube tu lista de IMDb IDs

Sube un .txt o pega la lista, una línea por ID. De cada película o episodio se quedan solo 2 torrents: el mejor en español y el mejor en inglés.

Formatos: tt0111161, tt0111161 Título (año), tt0944947 (si es una serie: todas las temporadas y episodios de una vez), tt0944947:s1:e1 Episodio o tt0944947:s1 Temporada (la expansión sale de Cinemeta, sin API key).

Ningún archivo seleccionado
Aún no has añadido IDs.

Tu navegador consulta los addons y Cinemeta directamente y en 1–2 minutos tienes los 2 torrents de cada título. Se guardan solo en este navegador (Dashboard → 💻 Este navegador). No escribe en el repositorio ni en Supabase.

La GitHub Action reemplaza watchlist.txt, publica los JSON y el addon Stremio en GitHub Pages y, si hay credenciales, hace UPSERT en Supabase.
